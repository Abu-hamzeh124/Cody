# كودي (Cody) 🚀

**منصة تفاعلية لتعلم البرمجة باللغة العربية**

---

## ما هي كودي؟

كودي هي منصة لتعلم البرمجة بطريقة فعالة وعملية، مصممة خصيصاً للمجتمع العربي. بدلاً من قراءة الشرح فقط، تكتب الكود مباشرة وتتحقق من إجابتك على الفور.

---

## المميزات

- 💻 **محرر كود متكامل** — اكتب كودك مباشرة في المتصفح بدون أي إعداد
- ✅ **تحقق تلقائي من الإجابات** — يتم تشغيل اختبارات تلقائية للتحقق من صحة كودك
- 📚 **نظام الكورسات** — كل كورس يحتوي على أقسام، وكل قسم يحتوي على دروس وتحديات
- 📊 **تتبع التقدم** — راقب مستواك وتقدمك في كل كورس
- 🔒 **نظام مستخدمين** — سجل حساباً وتابع رحلتك التعليمية

---

## التقنيات المستخدمة

| الجزء | التقنية |
|-------|---------|
| الواجهة الأمامية | React + TypeScript + Tailwind CSS |
| الخادم | Node.js + Express + TypeScript |
| قاعدة البيانات | SQLite + Drizzle ORM |
| تنفيذ الكود | Docker (python:3.11-slim) |
| المصادقة | JWT |

---

## كيف يعمل تنفيذ الكود؟

عند إرسال كودك، يتم:
1. إنشاء حاوية Docker معزولة
2. تشغيل كودك مع ملف الاختبارات
3. إرجاع النتيجة (نجح / فشل)
4. حذف الحاوية تلقائياً

هذا يضمن أمان كامل وعزل تام لكل مستخدم.

## تشغيل المشروع محلياً

### المتطلبات
- Node.js 18+
- Docker
- Git

### الخطوات

```bash
# استنساخ المشروع
git clone https://github.com/yourusername/cody.git
cd cody

# تشغيل الخادم
cd backend
npm install
npm run dev

# تشغيل الواجهة (في terminal جديد)
cd frontend
npm install
npm run dev
```

ثم افتح المتصفح على `http://localhost:5173`
